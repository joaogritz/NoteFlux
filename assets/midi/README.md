# MIDIs de teste

Arquivos criados pelo próprio projeto, livres para uso nos testes.

| Arquivo                | Conteúdo esperado                                                                     |
| ---------------------- | ------------------------------------------------------------------------------------- |
| `teste-escala.mid`     | 120 BPM · duração 4 s · 2 trilhas · 14 notas ("Melodia": 8 notas, "Acordes": 6 notas) |
| `arquivo-invalido.mid` | Texto comum com extensão `.mid`. Deve gerar mensagem de erro, sem travar o app.       |

Só adicione aqui MIDIs de terceiros se a licença permitir. Registre a origem e a licença nesta tabela.
